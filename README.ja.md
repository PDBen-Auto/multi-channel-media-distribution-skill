## 複数チャネルのメディア展開

`multi-channel-media-distribution`

検証済み企画から Facebook、Reddit、TikTok、YouTube、X、Instagram、LinkedIn 向けに展開し、指定されたチャネルだけを使います。

スキルディレクトリ: `.`

**実装の根拠と依存関係**

Agent、根拠、利用権のある素材、保存権限。補助ツールは Python 3.10+。動画ツール・FFmpeg・最新規則は必要時。公開操作には確認済みアカウント、接続、明示許可が必要です。

**入力**

対象者・目標・言語・CTA・順序付き企画、素材権利、チャネル別編集/提出権限、投稿先・公開範囲・規則・既存台帳。外部書込なしが既定です。

**出力**

input/work/output に共通根拠・実素材、媒体別原稿、レビュー/引継ぎ、実行台帳、移動可能な Markdown と単一 HTML レポート。

[実行手順 · 制約と停止条件 · 依頼例](references/i18n/ja.md)

> 次のスキルを使用してください： `$multi-channel-media-distribution` — 検証済み商品から七媒体の英語パッケージを作り、編集画面を順次準備して最終提出をユーザーに残します。日本語で回答し、根拠、不明点、操作権限を維持してください。
