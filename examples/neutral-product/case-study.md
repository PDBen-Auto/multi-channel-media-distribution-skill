# 脱敏重建：一个配件预览如何走完七渠道流程

## 案例性质

这是实际项目的方法复盘，经重新撰写和泛化后呈现。产品改为中性“发光户外配件概念”，不包含真实品牌、账号、人物、帖子URL、商业资料、原始图片/视频、截图、聊天、项目/对话ID或本机路径。它解释已观察的流程经验，不提供可公开验证的原始业务证明，不声称匿名化绝对不可重识别。

旁边的 `brief.json` 和 `scripts/demo.py` 是**另行编写的合成演练**，不是该历史项目的数据导出；合成事件不等于真实发布证据。演练包含“提交结果未知”这一恢复测试，不能据此断言历史项目出现同样状态。

## 需求与前置条件

资料只有两张设计图和一段样件视频，目标是英文新品预览、三张不同主题的传播图、横竖短片及七渠道独立文案。缺少完整规格、适配、价格、上市与性能证据。因此选用first look/preview语义和信息需求CTA，不写开售、合法性、安全改善或已验证效果。

制作可先进行；上传与最终提交后来有明确阶段授权。最终公开按钮由用户点击，不因此阻断已获准的研究、制作和编辑。换一个使用者时，必须重新读取该次权限，不复制这个历史边界作为永远禁止/允许规则。

## 阶段一：共同事实和职责

把产品事实、未知项、来源/权利、语言、受众假设与CTA固化为共用基线。共享制作负责图片/视频，七渠道分别改稿，避免生成七套互相矛盾的素材。审查职责负责看实际成品，不只看作者报告。

品牌标志不能证明发布者任职，车型指称不能暗示官方背书。用户的关系说明与后续账号资料可能不一致，这类差异应向用户核实而不是自动猜测。公开副作用与本地制作权限分别记录。

## 阶段二：不是“可播放”就等于好视频

初版约20秒，编码和播放可以通过，但用户明确认为像幻灯片，要求更强动态和吸引力。原技术PASS无法满足新质量目标。

返工改用真实样件中的连续变化、短镜头节奏、切片/遮罩、动态图形和英文入场文字，形成约18秒横竖候选。夸张放在剪辑和表达，不伪造安装、功能或实测性能。保留旧版为superseded，不改名冒充新片。

样件画面与渲染设计不同，分段标注bench sample与visualization，不能合并证明最终量产SKU。输出画布分辨率与源清晰度分别记录，不把升采样称原生高清。

## 阶段三：当前字节对应当前审查

对最终文件完整解码、实际正常速度播放到ended，检查开头、运动、字幕、转场、产品外形和横竖构图；来源映射与声轨复现另查。音频链正常不证明主观听感，仍留下真实试听待办。

审核入口使用相对资源与哈希，手机尺寸也检查。代理页面加载真实媒体的测试明确说明环境，不冒充原生file协议或平台预览验证。新片替换后，渠道旧视频稿需要重新核来源、时长和披露，不能直接继承旧审查。

## 阶段四：串行编辑与人工接手

渠道顺序为 Facebook → Reddit → TikTok → YouTube → X → Instagram → LinkedIn。一次一个浏览器操作者，先核实际账号、发布位置和查重，再正常选文件、回读正文和预览。

文件权限限制出现时，媒体数为0，即便正文已填也不标就绪；交用户手选指定文件。Instagram手选后重新核正确视频、9:16裁切、封面、完整播放和配文。浏览器超时/网址无法识别时停止受阻动作，不能换账号或强行注入。

## 观察到的结果边界

以下是提炼时读取的本地记录和必要对话证据所支持的历史状态，不是重新访问各平台的实时认证：

| 渠道 | 记录支持的层级 | 尚不能声称 |
|---|---|---|
| Facebook / Reddit / X | 三项账号内帖子核验，用户负责提交 | 三项均已匿名公共访问认证，或具有增长/使用效果 |
| TikTok | 用户取消 | 应自动恢复或已有发布 |
| YouTube | 编辑准备，未记录已验证发布 | 公开成功 |
| Instagram | 编辑器预览/配文完成，停在用户提交前 | 用户已分享或公共页已验证 |
| LinkedIn | 正文恢复、图片等待手选，连接/身份披露还有待办 | 媒体已上传、编辑器完全就绪或发布完成 |

因此本案例是**有可复用成品与局部执行证据的部分完成案例**。不是七站发布成功、用户全盘接受、公开商业案例、ROI或市场适配证明。

## 可迁移经验

1. 一次维护事实与共享资产，每平台按真实读者/位置改写。
2. 创意验收优先匹配用户质量目标，技术指标只能支撑其中一层。
3. 新字节重审，旧稿/来源映射/字幕/时长一起检查。
4. 外部写入按权限推进，人工接手是准确结果而非假失败或假成功。
5. 所有渠道保留真实状态；未知提交先对账再重试，取消项不复活。
6. 换电脑带走方法、当前基线、来源与状态，不搬登录态或全量聊天。
