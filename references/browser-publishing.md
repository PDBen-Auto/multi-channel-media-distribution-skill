# 浏览器编辑、提交与分层核验

## 会话与队列

每次发现本轮工具、会话和权限。指定一个操作持有人和渠道，记录目标账号/位置及授权。已登录浏览器、隔离测试浏览器、已保存凭据、可上传能力不是同一状态。复用可信现有会话，不新建替代账号/profile伪装已登录。

进入前读取最新页面；核账号、身份、品牌关系、权限、可见性与适用规则。查同主题/同日已有帖子、草稿和管理记录。尚有结果不明的提交时，先核验再恢复，不重复创建帖子。默认顺序可以调整，取消项明确跳过。

## 编辑和上传

1. 本地先准备最终文字、媒体、顺序和披露，核实际文件hash。
2. 使用平台正常文件选择入口和受支持工具。打开文件框或填入路径不是上传成功；必须看到正确数量、顺序和预览。
3. 验证裁切、封面、安全区、ALT/字幕、视频时长/音频和可见性；逐字回读正文，检查链接/标签未丢。
4. 账号配置与用户关于利益关系的说明冲突时，核实当前关系；旧资料不是新的用户决定。未消除实质披露冲突不提交。
5. 只在实际预览和必需项满足后标 `editor_ready_unpublished`。素材0张只能 `assets_waiting_manual` 或blocked。

不支持文件注入、正常控件不可达、策略拒绝或无法识别当前网页时，停止该动作。不要更改浏览器安全设置、force click、任意JS派发事件或反复盲点。留下手选文件的精确路径与需要核实的后续步骤；由用户完成后重新核验预览。

## 提交

`none`：不提交。`user`：保留真实就绪编辑器，由用户点击。`assistant`：只有当前明确授权、审查和全部前提具备才可点击准确提交控件。普通发布权限不包含付费推广、广告、付款、私信、群发或账号设置。

提交动作不等于结果。超时、跳转、编辑器消失或用户说“好了”均需确认上下文。记录 `submission_unknown` 并先查现有内容；不得因为没看见成功就重复点。完成核验后再决定前进、恢复就绪或标submitted。

## 状态与证据

| 状态 | 证据含义 | 还不能声称 |
|---|---|---|
| `queued` / `content_candidate` | 排队或本地候选 | 编辑或发布完成 |
| `assets_waiting_manual` | 需要用户通过正常入口选文件 | 已上传或已就绪 |
| `editor_ready_unpublished` | 正确账号/位置、素材、文案和预览已检查 | 已提交 |
| `submitted_processing` | 真实提交/平台接受信号，仍处理中 | 管理记录或公共可见 |
| `submission_unknown` | 发生不确定动作，需对账 | 已发、没发或可以安全重发 |
| `manager_verified` | 管理页面存在对应记录/ID/时间 | 外部公共可访问 |
| `account_post_verified` | 当前账号内实际帖子详情已核实 | 匿名或公共访问已通过 |
| `public_verified` | 实际公共详情页核实对应内容与媒体 | 增长、转化或所有地域可访问 |
| `blocked` / `cancelled_by_user` | 具体阻塞 / 当前用户取消 | 自动重试成功或自动恢复 |

顺序核查：提交信号→管理记录→账号帖子→公共详情。某平台无独立管理界面时可使用真实账号帖子证据并说明缺环，不能制造管理记录。公共页面失败时保留已证实层级及错误，不能猜URL。ID、时间、URL未知用null；时间区分平台显示时区和采集时间。

## 清理与恢复

关闭本轮临时搜索/规范/验证页并核实；保留用户交接编辑器需要明确记录。不要关闭用户原有标签或进程。报告浏览器工具限制与网站限制分别是什么。

中断后先读本地state/evidence和当前页面；核素材版本、草稿、已发记录及账号，才恢复。新机器没有旧编辑页/登录态，不假称无缝续传。只读回查也可能计入浏览，不能把自采流量当增长因果。
