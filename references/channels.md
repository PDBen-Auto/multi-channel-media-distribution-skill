# 七渠道编辑方法与运行时规则

以下是编辑框架，不是今日平台规格或账号功能认证。每次记录 `title / official URL / readAt / observed rule / exact applicability / limitation`。能打开链接不等于读完规则；搜索摘要不等于官方全文。发布日期unknown就写unknown。

| 渠道 | 编辑重点 | 发布前必须核实 |
|---|---|---|
| Facebook | 根据个人/Page/Group读者重写；首图讲清主题，图片次序展开细节；图文和Reels可不同表达 | 发布主体/位置权限、公开范围、Group规则、原创/AI/商业披露与实际媒体限制 |
| Reddit | 先提供社区有用的信息/讨论，再准确披露关联；不假装买家、车主或独立体验者 | 具体subreddit侧栏/规则/置顶/推广外链许可、flair、账号资格；不合规则暂不投递 |
| TikTok | 第一秒动机、真实运动、竖向构图、可读字幕、封面与自然CTA | 当前网页/设备支持形式、账号上传资格、音乐/商业内容披露、平台裁切和可见性 |
| YouTube | 明确Shorts或普通视频，标题承诺与实片一致；描述提供来源和适当披露 | 实际频道、形式识别、受众设置、版权检查、缩略图/字幕、处理状态和可见性；不能自动当儿童内容或非儿童内容 |
| X | 一条核心事实/观点；必要时连续帖但先规划顺序；媒体与文字不互相矛盾 | 当前账号字数/功能及平台计数（URL/Unicode可能不同）、媒体支持、顺序、可见性/披露；本地len仅诊断 |
| Instagram | 明确Feed/Carousel/Reels；封面、裁切、序列和配文相互配合 | 账号/发布位置、实际9:16或方形裁切、字幕安全区、音频和封面；预览完整播放后再交接 |
| LinkedIn | 针对职业/行业读者，说明真实设计/使用问题和证据；避免夸张营销 | 个人/公司Page权限、当前身份与品牌关系、普通帖/推广之别、媒体说明、公开范围 |

## 官方入口（执行时再读取）

- Meta：`https://transparency.meta.com/policies/`，`https://www.facebook.com/help/`，`https://help.instagram.com/`。
- Reddit：`https://redditinc.com/policies/content-policy`，`https://support.reddithelp.com/`；具体社区页面规则另核。
- TikTok：`https://www.tiktok.com/community-guidelines`，`https://support.tiktok.com/`；商业内容和音乐权限按实际用途读取。
- YouTube：`https://support.google.com/youtube/`，`https://www.youtube.com/howyoutubeworks/policies/community-guidelines/`。
- X：`https://help.x.com/en/rules-and-policies`。
- LinkedIn：`https://www.linkedin.com/legal/professional-community-policies`，`https://www.linkedin.com/help/linkedin`。

入口可能迁移/需要登录。记录真实错误和实际替代官方页；某个搜索服务404不归因平台故障。未取得适用规则时可写明确未核验的本地候选，不认证发布合规，不捏造数字限制。

## 每渠道内容合同

1. `placement / content type / primary audience / communication goal`。
2. `main`: 可直接复制的标题、正文或description、标签、CTA；未知项直接省略，不留价格/购买链接占位符。
3. `alternative`: 只有实际有用的短版、视频版或另一获准位置才提供。
4. `mediaRoles`: 对应真实素材路径、版本、顺序、ALT、封面/字幕；不存在就标pending，不能造hash。
5. `disclosure`: 已核实品牌关系/补偿/赠品/AI示意/样件来源及该平台实际要求。
6. `officialSources / prepublishChecks / unresolved`：内部核查，与读者稿分离。

同一事实必须一致，语气与结构可变。没有证据就不写通用适配、防水、安全提升、合法上路、已开售、销量、评价或稀缺性。不把一个案例的特定产品禁用词扩展为所有品类固定限制，应按本轮证据判断。
