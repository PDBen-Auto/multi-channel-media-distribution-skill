# 다채널 미디어 배포

`multi-channel-media-distribution` · 한국어

## 목적과 적용 범위

검증된 기획에서 Facebook, Reddit, TikTok, YouTube, X, Instagram, LinkedIn용 콘텐츠를 만들며 사용자가 선택한 채널만 적용합니다.

## 구현 근거와 의존성

Agent·근거·사용권 자료·출력 권한이 필요합니다. 보조 도구는 Python 3.10+, 미디어 도구/FFmpeg·최신 규칙은 조건부입니다. 온라인 작업은 확인된 계정·연결·명시 허가가 필요합니다.

## 입력

대상·목표·언어·CTA·채널 순서 기획, 자료 권리, 채널별 편집/제출 권한, 목적지·가시성·규칙·기존 기록. 기본값은 외부 쓰기 없음입니다.

## 출력

input/work/output의 공유 근거·실제 미디어, 채널 문안, 검토/전달, 실행 기록, 이동 가능한 Markdown과 자체 포함 HTML 보고서.

## 실행 절차

1. 최신 요구 복구
2. 사실·자료·관계 확인
3. 공유 제작과 채널별 조정
4. 실제 파일·전체 재생·모바일 점검
5. 편집기 직렬 준비와 업로드 건수/순서 확인
6. 사용자 제출이면 버튼 전 중단
7. 제출·관리 기록·공개 상세를 따로 검증하고 불명확한 작업은 재시도 전 대조.

## 제약과 중단 조건

스크립트는 영상이 아니고 편집 완료는 게시 완료가 아닙니다. 합성 예시는 실제 게시 증명이 아닙니다. 권한·CAPTCHA·업로드 미지원·정책 거절 시 해당 단계만 멈추고 독립 작업을 계속합니다.

## 요청 예시

다음 스킬을 사용하세요: `$multi-channel-media-distribution` — 검증된 제품으로 영어 일곱 채널 패키지를 만들고 편집기를 순차 준비한 뒤 최종 제출은 사용자에게 맡깁니다. 한국어로 답하고 근거, 미확인 사항과 작업 권한을 유지하세요.

## 전체 명세

[스킬 진입점과 상세 자료](../../SKILL.md).

사용자가 명시한 출력 언어를 따르고, 지정이 없으면 요청 언어를 따릅니다. 명령, 스킬 ID, JSON 키, 열거값, 단위와 원문 인용은 유지합니다. 번역과 원문을 구분하고 언어로 국가, 통화, 관할을 추정하지 않습니다. 전체 명세의 관련 자료를 읽고 기존 검증과 권한 조건을 적용합니다.

전달 전에 입력, 근거, 결측값, 출력 파일과 원래 완료 기준을 대조합니다. 실행하지 않은 단계는 미검증으로 표시하며 스크립트의 정상 종료를 업무 검증 성공으로 취급하지 않습니다.

## 언어 지원과 검증

이 문서는 목적, 전제, 입출력, 절차, 예시와 제약을 다루는 한국어 운영 가이드이며 모든 참고 문서의 문장별 번역은 아닙니다. 상세 기술 자료, 과거 사례, 스크립트 오류, 예제 화면과 이미지는 원래 언어를 유지합니다. 요청 시 해당 언어로 설명할 수 있습니다. 구조, 링크와 핵심 제약을 확인했으나 각 언어 원어민 교정은 수행하지 않았습니다.
