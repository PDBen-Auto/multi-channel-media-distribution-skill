# 複数チャネルのメディア展開

`multi-channel-media-distribution` · 日本語

## 目的と適用範囲

検証済み企画から Facebook、Reddit、TikTok、YouTube、X、Instagram、LinkedIn 向けに展開し、指定されたチャネルだけを使います。

## 実装の根拠と依存関係

Agent、根拠、利用権のある素材、保存権限。補助ツールは Python 3.10+。動画ツール・FFmpeg・最新規則は必要時。公開操作には確認済みアカウント、接続、明示許可が必要です。

## 入力

対象者・目標・言語・CTA・順序付き企画、素材権利、チャネル別編集/提出権限、投稿先・公開範囲・規則・既存台帳。外部書込なしが既定です。
